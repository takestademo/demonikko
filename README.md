# 日興産業株式会社 コーポレートサイト

日興産業株式会社（NIKKO SANGYO CO., LTD.）の公式コーポレートサイトです。

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` でサイトが確認できます。

## プロダクションビルド

```bash
npm run build
npm start
```

## 構成

- `app/` — ページコンポーネント (App Router)
- `components/` — 共通コンポーネント (Header, Footer など)
- `lib/` — ユーティリティ・データ
- `public/images/` — 画像アセット
