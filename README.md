# 日興産業株式会社 コーポレートサイト

日興産業株式会社（NIKKO SANGYO CO., LTD.）の公式コーポレートサイトです。

## 技術スタック

- [Next.js 16](https://nextjs.org) (App Router)
- [React 19](https://react.dev)
- [Tailwind CSS v4](https://tailwindcss.com)
- TypeScript

## 開発環境の起動

```bash
npm install
npm run dev
```

`http://localhost:3000` でサイトが確認できます。

## ビルド

```bash
npm run build
npm run start
```

## ディレクトリ構成

- `app/` — ページコンポーネント (App Router)
- `components/` — 共通コンポーネント (Header, Footer, etc.)
- `lib/` — ユーティリティ・データ
- `public/images/` — 画像アセット
